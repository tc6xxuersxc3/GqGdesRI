# 项目简介

## 核心功能
- 基于YOLOv8的街景数字检测系统，能够识别0-9共10类数字
- 支持多种输入方式：单张图片、图片文件夹、视频文件、本地摄像头
- 提供用户界面实时显示目标位置、目标总数、置信度等信息
- 支持批量检测功能，可查看每一张检测结果
- 可自定义置信度和IOU阈值
- 可选择显示标签和原图
- 支持选择检测模型
- 提供检测结果保存功能

## 适用场景
- 街景图像中的数字识别与分析
- 视频监控中的数字检测
- 实时摄像头数字监测
- 批量图像处理与分析

## 技术特点
- 使用Python 3.9开发
- 依赖库包括opencv-python、PyQt5、ultralytics、torch1.9等
- 提供完整的UI界面，基于PyQt5开发
- 包含40000张标注数据集用于模型训练
- 已训练好可直接使用的模型
- 支持Pycharm+Anaconda或VSCode+Anaconda开发环境
